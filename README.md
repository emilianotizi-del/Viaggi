# Emiliano & Poli · Viaggi

Archivio web personale dei viaggi di Emiliano e Polina.
Sito: https://emilianotizi-del.github.io/Viaggi/

- `index.html` home · `viaggi.html` archivio · `idee.html` viaggi futuri · `roma.html` itinerari di Roma
- Un diario per viaggio (`portogallo.html`, `milano.html`, `venezia.html`) con CSS dedicato
- `portogallo-guida.html`: guida preparata prima del viaggio (pagina statica)
- Media in `assets/<viaggio>/{foto,video,poster}` — WebP per le foto, MP4 originali per i video, poster JPEG separati
- Nessun Base64 nell'HTML, nessun payload da ricomporre nel browser
- Sito pubblico ma non indicizzato (`noindex` in ogni pagina)

I branch `main` e `site-archivio-viaggi` vanno mantenuti sincronizzati.
